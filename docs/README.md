# QData GitHub Pages

This folder is the GitHub Pages project site for QData.

To publish it:

1. Push the repository to GitHub.
2. Open repository `Settings` -> `Pages`.
3. Select `Deploy from a branch`.
4. Choose branch `main` and folder `/docs`.
5. Save, then open the generated GitHub Pages URL.

The page is designed for technical review: it summarizes the free-source quant research database, verification outputs, source-governance model and project story without requiring the reader to inspect the full backend documentation.

Project companion files in the repository:

- English README: `../README_EN.md`
- Architecture diagram: `assets/qdata-architecture.svg`
- Architecture note: `architecture.md`
- Notebook: `../notebooks/free_source_factor_backtest.ipynb`
