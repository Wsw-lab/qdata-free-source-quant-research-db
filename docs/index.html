Free Source Strategy

The project is deliberately framed as a research database. Free sources can be excellent for learning, validation and strategy research, while commercial production use needs separate authorization.

Source Matrix

Source Research Use Governance Rule
AKShare Daily bars, symbols, calendars and public market datasets Research and validation first; upstream terms reviewed before commercial use
BaoStock Historical A-share data and financial statement candidates Socket timeout guard and recovery workflows protect long-running jobs
Tushare free tier Free token or quota-limited supplementary checks Token is optional and never committed; quota and terms are tracked
Official public pages Exchange, announcement and macro public data candidates Cache, attribution and redistribution questions remain explicit blockers

Project Narrative

This project shows how I think about data as infrastructure: not simply downloading market prices, but building a controlled research environment where every dataset has lineage, quality checks and source-risk evidence.

The current version intentionally focuses on a zero-cost research route. It documents software engineering choices, quantitative finance assumptions and independent project execution in a reproducible repository.

The next technical milestone is to publish more example notebooks: factor construction, PIT financial screening, event-study samples and a small backtest powered by the QData SDK.
