Evidence Boundaries

Current evidence is divided into offline deterministic checks, bounded local selectors, and work that still needs real integration.

Synthetic fixtures offline SDK examples and research_snapshot_v1 contract samples

Real integration pending query plans, cross-store transactions, recovery, performance and sustained operation

Project Narrative

This project shows how I think about data as infrastructure: not simply downloading market prices, but building a controlled research environment where every dataset has lineage, quality checks and source-risk evidence.

The current version focuses on deterministic synthetic fixtures and explicit evidence boundaries. Free/public providers remain candidates until their legal, coverage and service constraints are reviewed.

The next technical milestone is broader real-database integration plus additional reference-arithmetic, PIT-screening and event-study contract examples.
